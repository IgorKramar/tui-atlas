# Changelog / История изменений

## 0.2.0 — 2026-10-28

### English

- First public release of TUI Atlas under the MIT license.
- English and Russian interface and curated cards; `--lang en|ru`, persistent `L` switching, and search in both languages.
- 37 app cards, 874 shortcuts, and 284 command examples, with primary-source references.
- Local CLI help and documentation, editable launch arguments, and return to Atlas after a child app exits.
- Native Linux x86_64 and ARM64 CI, tested binary archives, source build information, and SHA256 checksums.
- English and Russian READMEs, data contracts, and application screenshots.

### Русский

- Первый публичный релиз TUI Atlas под лицензией MIT.
- Интерфейс и карточки на английском и русском; `--lang en|ru`, сохранение выбора по `L`, поиск на обоих языках.
- 37 карточек, 874 сочетания и 284 примера команд со ссылками на первичные источники.
- Локальная CLI-справка и документация, редактируемые аргументы запуска и возврат в Atlas после выхода из дочерней программы.
- Нативный CI для Linux x86_64 и ARM64, проверенные бинарные архивы, сведения о сборке и контрольные суммы SHA256.
- README, контракт данных и скриншоты на двух языках.

The catalog is a curated snapshot, not a package manager or live system inventory.
Каталог — подготовленный снимок, а не пакетный менеджер или живая инвентаризация системы.
