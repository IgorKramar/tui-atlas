# Контракт данных каталога

[English](data-contract.md) · **Русский**

Каталог встроен в исполняемый файл. После изменения JSON требуется пересборка; отдельные файлы переопределения во время запуска не читаются.

## Инвентаризация

`data/inventory.json` — массив, по одной записи на приложение. Программа читает обязательные строковые поля:

| Поле | Значение |
|:---|:---|
| `id` | Постоянный идентификатор, например `nvim`; ему соответствует одна карточка |
| `name` | Отображаемое название |
| `group` | Отображаемая категория |
| `version` | Версия из подготовленного снимка; при запуске не определяется |
| `executable` | Имя команды или известный путь; `~/` раскрывается в домашний каталог текущего пользователя |

Существующие `command` и `source` описывают происхождение записи и не используются при запуске. Имена без `/` ищутся в `PATH`. Пути с `/` проверяются напрямую; если записанного пути нет, повторного поиска в `PATH` не происходит. Доступным считается только обычный исполняемый файл.

## Карточки

Каждый `data/guides-*.json` содержит массив карточек. На каждый ID инвентаризации нужна ровно одна карточка; дубликаты, пропущенные карточки и карточки без записи инвентаризации отклоняются.

| Обязательное поле | Тип и значение |
|:---|:---|
| `id` | Строка, совпадает с идентификатором инвентаризации |
| `description` | Строка, назначение программы на русском языке |
| `launch_args` | Массив стандартных аргументов без имени программы |
| `help_args` | Массив безопасных аргументов справки либо `null`, если отдельного безопасного вызова нет |
| `man_pages` | Массив имён локальных man-страниц |
| `doc_files` | Массив объектов со строковыми `path` и `label` |
| `shortcuts` | Массив объектов со строковыми `key`, `action`, `context` |
| `examples` | Массив объектов со строковыми `command`, `description` |
| `notes` | Массив строк |
| `sources` | Массив объектов со строковыми `title`, `location` |

`context` обозначает экран, режим или локальное переопределение. Разделяйте стандартные сочетания и обнаруженные пользовательские настройки. Примеры — справочный текст; окно запуска редактирует только аргументы выбранной программы.

Используйте проверенные локальные man-страницы, документацию, безопасный вывод справки или официальные источники. Не добавляйте непроверенные комбинации. Фиксируйте версии и различия между платформами и конфигурациями.

## Английский перевод

Русские строки переводятся через плоские словари `data/catalog-en-a.json`, `data/catalog-en-b.json`, `data/catalog-en-c.json`. Ключи должны быть уникальны во всех трёх файлах. Разделение нужно для удобства поддержки и не соответствует отдельным файлам карточек.

Переводятся названия и категории инвентаризации, описания карточек, клавиши/действия/контексты, команды и описания примеров, примечания, подписи документов и названия источников. В примерах можно переводить условные имена, но **имена программ и буквальные флаги должны оставаться неизменными**. Сами сочетания клавиш не меняются; переводятся только пояснения к ним.

Не переводите ID, версии, пути к программам, аргументы запуска и справки, имена man-страниц, пути к документам и адреса источников. Поиск индексирует исходный и переведённый текст. Строки без перевода показываются в исходном виде; тесты требуют английский перевод для каждой встроенной отображаемой строки с кириллицей.

## Локальные файлы и безопасность

`doc_files.path` может начинаться с `~/`. Включайте только документацию и известные файлы сочетаний: никаких профилей авторизации, токенов, приватных ключей и файлов рабочих доступов. Отсутствующие источники показываются как недоступные и не скачиваются. Atlas также проверяет небольшой явный список личных файлов сочетаний tmux, Yazi, nchat и Neovim, если они существуют.

Открытие раздела CLI может выполнить настроенную команду справки. `help_args` должны быть неинтерактивными и не выполнять запись или сетевые операции; иначе задайте `null`. Полная программа запускается после явного подтверждения аргументов пользователем. Стандартные `cfdisk --read-only` и K9s `--readonly` заданы намеренно.

## Проверка изменения

```sh
cargo fmt --all -- --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo build --release --locked
python3 tests/terminal_smoke.py target/release/tui-atlas
```

Тесты проверяют покрытие карточек и переводов, сохранение имён команд, флагов и путей к источникам. Просмотрите оба языка, убедитесь, что длинный текст помещается в широком и узком окне. Если изменились счётчики карточек или примеров, обновите оба README.
