## English

**TUI Atlas 0.2.0** is the first public release: a terminal app catalog, cheatsheets, local help, and launcher in one dark, rounded TUI.

- 37 apps, 874 shortcuts, 284 command examples.
- English and Russian UI and cards. Use `--lang en|ru` or `L`; search works in both languages.
- Editable launch arguments and return to Atlas when the child app exits.
- Local documentation and help with output/time limits.
- MIT license, bilingual README, native x86_64/ARM64 CI, and tested release archives.

### Downloads

Choose `x86_64-unknown-linux-gnu` for Intel/AMD 64-bit Linux or `aarch64-unknown-linux-gnu` for ARM64 Linux. Both require glibc and are built on Ubuntu 22.04; musl/Alpine binaries are not provided. Verify the selected archive against `SHA256SUMS` before extracting. Each archive includes `BUILDINFO.json` with the source commit and target.

No Rust toolchain is needed for the prebuilt binary. Third-party terminal apps are installed separately. The catalog is a 27 October 2026 snapshot, with the Forge Deck card added on 28 October; version labels and local keybindings are not automatically adapted to your system.

## Русский

**TUI Atlas 0.2.0** — первый публичный релиз: каталог терминальных приложений, читшиты, локальная справка и запуск в одном TUI с тёмной темой и скруглёнными панелями.

- 37 приложений, 874 сочетания, 284 примера команд.
- Интерфейс и карточки EN/RU. Язык выбирается через `--lang en|ru` или `L`; поиск работает на обоих языках.
- Редактируемые аргументы запуска и возврат в Atlas после выхода из дочерней программы.
- Локальная документация и справка с ограничениями времени и объёма.
- MIT, README на двух языках, нативный CI для x86_64/ARM64 и проверенные релизные архивы.

### Загрузка

Для Intel/AMD 64-bit Linux выберите `x86_64-unknown-linux-gnu`, для ARM64 Linux — `aarch64-unknown-linux-gnu`. Обе сборки используют glibc и Ubuntu 22.04; бинарников musl/Alpine нет. Перед распаковкой сверьте выбранный архив с `SHA256SUMS`. В каждом архиве есть `BUILDINFO.json` с коммитом исходников и платформой.

Для готового бинарника Rust не нужен. Терминальные приложения устанавливаются отдельно. Каталог — снимок от 27 октября 2026 года с карточкой Forge Deck от 28 октября; версии и локальные сочетания не подстраиваются под вашу систему автоматически.
